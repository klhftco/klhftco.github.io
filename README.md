# klhftco.github.io

Personal research website for Leo Huang. Built from [Jon Barron's template](https://github.com/jonbarron/jonbarron_website).

The site is plain HTML with no build step. Edit `index.html` for content and `stylesheet.css` for styling. Thumbnails go in `images/` at 160x160, and the CV goes in `data/Leo_Huang_CV.pdf`.

Local preview:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
